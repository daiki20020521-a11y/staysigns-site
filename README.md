# StaySigns Studio

民泊・小規模宿泊施設向けの多言語案内作成ツールの紹介サイトです。

- 公式ページ（GitHub Pagesのデプロイ完了後に公開）：https://daiki20020521-a11y.github.io/staysigns-site/
- 無料デモ： https://daiki20020521-a11y.github.io/staysigns-site/demo.html
- デプロイ設定：GitHub Actions `.github/workflows/publish.yml`
- 公開サイト生成：`python build_site.py`
- 記事原稿：`articles.json`（指定週に順次公開、初回4記事）

このリポジトリには無料で公開できる内容のみを配置しています。
有料商品は別途販売プラットフォームで管理します。
